# 功能缺口清单（2026-11-27 核对）

> 核对口径：以 `apps/desktop` 真实代码 + `apps/daemon` 实际 RPC 为准，不按原型文档推断。
> 配套文档：`PARITY.zh.md`（逐屏对齐结论）。

## 一句话结论

**25 屏界面全部落地**；功能分三档：

1. **真接后端、可用**：下载核心链路、云盘配置/浏览、回收站、设置、资源发现、更新检查。
2. **本地闭环、可用但单机**：16 屏（配对/好友/账号/节点/传送等），数据落 `LocalStore`，重启仍在，但不联网。
3. **缺口**：见下方四类。核心矛盾是 **daemon 只有 aria2 下载 RPC**，没有跨设备/账号/传送/节点挂载能力。

`falcon_set_global_option` / `falcon_get_global_stats` / `ping`。

| 缺口 | 对应屏 | 现状（本地已做部分） | 需后端提供 |

## C. 本地缺口（2026-11-27 已补 3 项，其余如实标注）

### C-已实现（本轮）

| 项 | 实现 |
|---|---|
| 二维码生成 | 新增自包含 `utils/qr_code.{hpp,cpp}`（字节模式 / 纠错 M / 版本 1-3，含 RS + 8 掩码选优），无第三方依赖。`ShowCodeDialog` 显示**真实可扫**二维码，码串就是 6 位码本身。端到端验证：生成器多项式、格式位（8 个掩码均与标准一致）、数据/ecc 码字、逆掩码解码均通过 |
| 扫码路径 | `PairCodeDialog` 扫码页改为「粘贴扫码得到的码」输入框 + 从剪贴板粘贴按钮；桌面无摄像头，扫码动作落地为等价的码串输入，与手输共用同一校验链路 |
| 托盘 2 项 | 「全部暂停」遍历最近一轮任务快照逐任务发暂停；「展示传送码」复用 `ShowCodeDialog` |
| 右键快捷键 | 表格/网格两视图右键菜单绑定 `Ctrl+P`（暂停/继续）、`Return`（打开文件）、`Ctrl+E`（打开文件夹）、`Ctrl+C`（复制链接） |

### C-未做（需后端 / 需跨库改造 / 做了会破坏一致性，不造假）

| 缺口 | 现状 | 为何未做 |
|---|---|---|
| 重命名 / 全选 | 菜单无这些项 | 重命名会改磁盘文件但 `TaskSnapshot.output_path` 仍指向旧路径（daemon 下一轮刷新覆盖，界面破碎）；表格为 `SingleSelection`，全选无意义（改 `ExtendedSelection` 牵动整套批量逻辑） |
| 云盘上传是假实现 | `storage_service.cpp::upload_file` 注释「简化实现：假设上传成功」 | `IResourceBrowser` 接口无 upload 虚方法，需给 S3/OSS/COS/Kodo/Upyun/WebDAV/FTP 七个 browser 全部实现并跨库改动，本机无 Qt 无法编译验证；不做假成功 |
| 「添加到云盘」只切页 | 右键/详情页按钮 → 主窗口切到云盘页 | 保留为导航入口（云盘页有上传 UI）；真实上传依赖上一条 |
| 文件详情缺字段 | 原始节点数、校验显示「—（快照无此字段）」 | 需 `TaskSnapshot` 增字段并让 daemon 填充 |
| 完成时间列（屏 5） | `TaskSnapshot` 无完成时间戳 | 同上：数据结构补字段 |
| 资源发现权重 | 引擎模型无权重字段，折叠区显示请求间隔 | 低优先级；若要对齐需扩 `engines.json` 模型 |

## D. 明确不做 / 非缺口

- **举报**：产品确认不做。daemon 无举报/审核接口，也没有举报内容落点与处理流程，前端加了入口也无处提交，属于纯摆设；当前代码未实现，不算缺口。
- **macOS 菜单栏**：原型声明本版不出图，Windows 托盘是唯一实现。
- **AirDrop 协议级接入**：AWDL 为 Apple 私有协议，原型已结论「只做系统分享面板入口」。
- **附近设备 / LocalSend 发现**：原型结论为第一期可做可不做，当前未接。
- **文件详情跳转云盘**：已实现（切页），但受 C 类上传假实现限制。

---

## 建议顺序

1. **先编译**：环境就绪后跑通 `-DFALCON_BUILD_DESKTOP=ON`，修编译错误——这是所有后续工作的前提。
2. ~~低成本补齐（托盘 2 项 / 右键快捷键 / 二维码）~~ **已完成**（2026-11-27），见 C-已实现。
3. **修假实现**：云盘上传需给 `IResourceBrowser` 加 upload 并在 7 个 browser 实现（跨库改造）；随 Qt 环境一并做，切勿假成功。
4. **后端 RPC（B 类）**：按产品优先级排期，先做跨设备中继与账号，再做传送/节点挂载。
5. **数据源字段**：`TaskSnapshot` 补完成时间/节点数/校验、引擎模型补权重，随 daemon 改造一并补。
