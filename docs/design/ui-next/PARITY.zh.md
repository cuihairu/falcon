# ui-next 原型 × 真实应用 逐屏核对表

本文件记录 `ui-next` 静态原型（25 屏）与真实 Qt6 桌面应用（`apps/desktop`）的逐屏核对结论。
核对日期：2026-11-26。

## 核对口径

- **原型屏号**：按 `index.html` 中 `.screen` 的 DOM / 翻页顺序编号（1–25），与 README 表格编号不同。
- **完全对齐**：字段、控件、交互基本一致。
- **部分对齐**：核心结构一致，细节（列名、文案、控件形态）有差异，已在本轮保守对齐或注明。
- **应用缺失 · 第一期**：原型有但应用无，且产品上属于当前阶段，部分需要新后端。
- **应用缺失 · 后续阶段**：原型自身标注「后续阶段 / 第一期可隐藏」，产品上一期明确不做。

## 数据可用性约束（核对中发现）

- `TaskSnapshot` **无完成时间戳**：原型的「完成时间」列无法做实，未造假数据。
- `TaskSnapshot` **无独立来源字段**：来源列从 `url` 的 host 派生（真实可用）。
- 搜索引擎模型**无权重字段**：折叠区显示请求间隔而非权重。
- `TrashEntry` 有 `deleted_at`：回收站「剩余天数」可做实。
