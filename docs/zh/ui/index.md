# UI 设计

本模块是 Falcon 桌面端 UI 设计的权威记录。它有意与核心/开发文档分开：核心页描述代码实际做什么，UI 页描述界面应该如何呈现和交互。

当前设计是 `docs/design/ui-next/` 下的单一可交互原型，取代了此前所有 UI 探索稿（旧稿已删除）。原型无依赖，可直接用浏览器打开。

## 页面

- [设计规范](/zh/ui/design-spec) — 完整 24 屏界面清单、主题系统、跨设备 / 账号与分享模型、协议取舍与平台差异。
- [桌面端重设计](/zh/ui/desktop-redesign) — 最初的视觉换代方向、信息架构、设计 token 与 Qt 落地策略。
- [界面设计原型](/zh/ui/design-prototypes) — 原型沿革、主题 token 对照与导出设计图库。

## 核心原则

- **一套设计、可切换强调色。** 暖橙为默认（延续现行品牌）；冷蓝、石墨绿是可切换主题而非竞品方案：布局、组件、间距、交互完全一致，仅 token 变化。
- **浅色 / 深色 / 跟随系统。** 模式入口在偏好设置 → 外观；auto 时跟随 `prefers-color-scheme`。
- **只做原型。** UI 原型不改生产代码。
