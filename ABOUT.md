# About Falcon

**Falcon** is a universal resource transfer engine and download platform designed for speed, security, and versatility. Built with modern C++17, it delivers one transfer core — HTTP, FTP, SFTP, WebDAV, BitTorrent, Metalink, object storage, and private-protocol compatibility — across all major platforms: Windows, macOS, and Linux.

## Our Mission

We believe downloading should be fast, secure, and effortless. Falcon combines cutting-edge technology with an intuitive interface to provide the ultimate downloading experience. Whether you're downloading large files, streaming media, or managing cloud storage, Falcon handles it all with ease.

## Key Features

### 🚀 High Performance
- Multi-threaded downloading for maximum speed
- Intelligent bandwidth management and throttling
- Resume interrupted downloads automatically
- Concurrent download support for multiple files

### 🌐 Universal Protocol Support
- **Standard Protocols**: HTTP/HTTPS, FTP/FTPS
- **P2P Networks**: BitTorrent, Magnet links
- **Cloud Storage**: Amazon S3, Alibaba Cloud OSS, Tencent COS, Qiniu Kodo, Upyun USS
- **Private Protocols**: Thunder (迅雷), QQDL (腾讯旋风), FlashGet, ED2K
- **Streaming**: HLS/DASH adaptive streaming

### 🔐 Enterprise-Grade Security
- AES-256 encrypted credential storage
- Master password protection
- Secure cloud storage authentication
- Proxy support with authentication

### 🎯 Advanced Features
- Remote directory browsing with rich metadata
- Built-in resource search engine
- Batch download management
- Cross-platform compatibility

## Technology Stack

- **Core**: C++17/20 with modern async programming
- **Networking**: libcurl for HTTP/FTP, libtorrent for BitTorrent
- **Security**: OpenSSL for encryption
- **Storage**: SQLite for configuration management
- **Build System**: CMake for cross-platform builds

## Open Source Commitment

Falcon is proudly open source under the Apache License 2.0. We believe in transparency, community collaboration, and the power of open-source software. Our vibrant community of developers and users continuously contributes to making Falcon better every day.

## Privacy & Security

Your privacy is our top priority. Falcon never collects personal data or tracks your downloads. All credentials are encrypted locally with industry-standard AES-256 encryption, ensuring your cloud storage accounts remain secure.
